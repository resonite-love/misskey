# メンション・指名と限定投稿のUI統一

更新日: 2026-11-13
対象: `2026.11.0-grid-space.15` / `2026.11.0-resonite-love.15`

## 表示と操作

通知画面のメンション・指名タブで、自鯖の投稿と連携先の旧アカウント宛ての投稿を時系列に混ぜる。指名タブは `specified` の投稿だけを表示する。公開メンション、本文にメンションがない指名投稿、センシティブなチャンネル内のメンションも対象にする。本文に旧アカウントの名前があっても、そのアカウントが指名先に含まれない限定投稿は取得しない。

各サーバーのページ位置を別々に持ち、URIで重複を除く。両方で読み取った時刻の範囲だけを表示する。タブの再読込ボタンとpull-to-refreshで新着を取得できる。非表示時は限定本文を消し、復帰時に同じタブの条件で権限を再確認する。

通知の宛先は連携先だけに表示する。ぐりすぺでは「→ れぞらぶ」、れぞらぶでは「→ ぐりすぺ」とし、自鯖宛てにはラベルを出さない。表示名は設定済みのチャンネル連携の役割で判定し、役割がない構成ではホスト名を使う。

限定投稿は通常の `MkNoteHeader`、`MkCwButton`、`MkPoll`、`MkReactionsViewer`、`MkMediaList` を使う。返信はチャンネル投稿と共通の `MkGridspacePostForm` を使い、通常の投稿フォームと同じスタイル、添付編集、絵文字・MFMの入力、プレビュー、投票編集を利用する。名義と公開範囲を表示し、指定された受信者を勝手に変更しない。チャンネル外の返信範囲は従来どおり、指名投稿への返信なら指名、それ以外はフォロワー限定になる。

## 権限と互換性

`gridspace/private-notes` に `mentions` と `direct` を追加した。取得と再検証で同じ宛先・公開範囲・ミュート条件を使い、カーソルも条件に結び付ける。通常の `notes/mentions` と外部サーバー向けのActivityPubは変更していない。通常検索・ホーム・プロフィールのセンシティブなチャンネルの除外条件も変更していない。

添付は認可済みのblobだけを表示し、連携先のファイルIDをローカルのドライブ操作へ渡さない。CWを閉じる、一覧から外れる、権限が失効する、タブを離れる場合はblobと画像ビューアーを破棄する。別に開いたファイル情報メニューも破棄する。返信フォームも非表示時に閉じ、通信結果が不明な送信はリクエストIDだけで確認する。

## 残る差分

限定投稿全体をローカルの `MkNote` に変換してキャッシュする方式ではない。表示部品を共有し、操作は旧アカウントの認可経路へ送る。チャンネル外の限定投稿のメニューはリンクのコピーが中心で、通常ノートのクリップ・削除など全操作を揃えたものではない。Renoteは無効のまま。親投稿・引用はリンクで開く。これらは今回の表示・返信フォームの共通化とは別に残る。
