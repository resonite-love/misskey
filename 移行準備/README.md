# GridSpace・れぞらぶ 移行準備

作成日: 2026-11-12。状態: 試験環境で OAuth 本人連携、フォローの初回コピー、新規投稿の共通 LTL とホーム表示、プロフィールの過去履歴、人物・過去投稿の横断検索を実装した。追加認可による旧アカウントの限定投稿・添付の閲覧と検索も実装した。限定投稿は通常ホーム・プロフィール・検索の一覧に合流し、旧名義での本文・CW の返信も実装した。追加認可による通知欄と未読バッジの統合も実装した。旧名義によるリアクション・投票・添付付き返信、限定投稿の MFM・カスタム絵文字、新規登録後の連携案内を追加した。本番環境は変更していない。現在の結果は [10-実装状況](10-実装状況.md) に記録する。

GridSpace は、れぞらぶの会話や人のつながりを引き継ぎながら、Resonite 以外にも話題を広げるコミュニティとする。`resonite.love` と `grid-space.io` を並行運用し、利用者が普段使うサイトを変えても会話を続けられるようにする。Misskey 標準のアカウント引っ越しは使わない。

## 状態の読み方

- 合意済み: このチャットで利用者が明示した要求。`R-` で始まる ID を付ける。
- 設計案: 要求を実現するための案。本文の「〜する」は実装済みという意味ではない。
- 未決: 利用者の選択、運用情報、検証結果が必要な事項。`Q-` で始まる ID を付ける。
- 確認済み事実: 指定したコミットのコード、またはリンクした資料で確認した事項。

設計案への異論がないことを承認とは扱わない。変更するときは決定ログ、関係する仕様、受け入れ条件を一緒に更新する。実装開始前に残る未決事項を確認する。

## 採用する基盤

作業先の `grid-space-misskey` は利用者の指定に基づいて `resonite-love/misskey` の `resonite-master` を基準にした。基準ブランチの `resonite-master` は `resonite-love/resonite-master` を追跡し、実装はそこから分けた `codex/gridspace-bridge` で進める。確認した基準バージョンは `2026.10.0-resonite-love.6`、コミットは `b28be53907a8eeebe90efc9741bd637278e15e1a`。

最初に確認した 2023 年版の `develop` ブランチと移行準備の資料は保持した。本番のれぞらぶがどの版かは未確認なので、配備前に調べる。ブランチの切り替え履歴は [現行実装調査](08-現行実装調査.md) を参照する。

## この段階で残る主な判断

1. 本番のれぞらぶのバージョンと、採用した基盤への更新・配備手順。
2. 連携解除後の公開プロフィール表示と、引き継いだ Follow の扱い。
3. 閉じたアプリへのプッシュ通知まで初回公開に含めるか。

旧側のフォロー一覧は連携時だけコピーする。以後、相手の新アカウントは新側の現在のフォロー・申請を基に自動追加し、手動の解除・取消・却下を尊重する。両サイトの同時更新後からローカル投稿を共有し、過去投稿も検索・スクロールで読めるようにする。旧名義での返信も要求として合意済み。詳しい範囲は [決定ログ](07-決定ログ.md) を参照する。
