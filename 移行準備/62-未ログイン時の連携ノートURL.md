# 未ログイン時の連携ノートURL

`/gridspace/private?noteId=...&channelId=...` は、ログインしていなくても開ける。

- 未ログインでは、投稿元が匿名閲覧を許可する投稿だけを確認し、元サーバーの通常ノートURLへ自動で移動する。リモートURLをコピーし直す必要はない。
- フォロワー限定・指名・投稿者のログイン必須設定・過去投稿の非表示設定・サーバーの訪問者向け制限を守る。取得できない場合は非表示とログイン案内を出す。
- サーバー間の公開投稿取得には既存の署名付き通信を使う。連携ユーザーの権限やOAuthトークンを使わない。
- 閲覧側がリモート投稿の本文を匿名公開しない設定なら、確認済みの投稿元URLだけを返す。本文や添付は返さない。
- ログイン中は従来どおり、ぐりすぺ側の画面で連携権限を使って読む。
- ページから離れたら取得を中止し、遅れて届いた応答で別ページから転送しない。

変更履歴の候補: 連携先ノートのURLを未ログインで開いた場合、公開が確認できた元ノートを自動で表示する。
